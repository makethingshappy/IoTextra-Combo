# SKU — IoTextra Combo

```
040601vvvtc2
```

| Field | Description |
|---|---|
| `040601` | Product code — IoTextra Combo |
| `vvv` | Version (e.g. 304 = version 3.04) |
| `t` | Type & Relay model |
| `c` | Communication |
| `2` | Fixed — ADS1115 ADC chip |

**Type & Relay model (t):**

| Value | Description |
|---|---|
| 1 | Pro · HF33F/005 Relay |
| 2 | Pro · ALQ105 Relay |
| 3 | Pro · G5Q-14 Relay |
| 4 | Pro · PE014005 Relay |
| 7 | Lite · ALQ105 Relay |
| 8 | Lite · G5Q-14 Relay |

**Communication (c):**

| Value | Description |
|---|---|
| 1 | HOST-12 connector |
| 2 | HOST-12 connector and two I²C connectors |
